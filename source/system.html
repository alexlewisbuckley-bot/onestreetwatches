Mobile design language

One navigation model, one type scale, one spacing rhythm, and a fixed set of components. Every screen is assembled from what is on this page. Nothing new is invented for a single section.

Space

A single 4px rhythm. Ten steps, no values in between — the old CSS used 32 different gaps.

Navigation

One model everywhere. A dock for destinations, sheets for decisions, full-screen for search.

Bottom dock Five destinations, always visible, thumb height. The only way to change place.
Bottom sheet Any decision that must not lose the user's place: filters, options, a case of watches.
Full screen Search only. It replaces the page because it replaces the task.
Back The browser's. We never draw our own back button — two back affordances is one too many.

Buttons

Four variants. One primary per screen — if two things look primary, neither is.
